
# 🛍️ ShopNest – E-Commerce Web App

ShopNest is a modern, responsive e-commerce web application built using HTML, CSS, and JavaScript. It simulates a complete online shopping experience with authentication, product browsing, cart, checkout, and admin controls — all powered by localStorage. 

## 🚀 Features

* 🔐 User authentication (Login/Register)
* 🛍 Product listing with search & filters
* 🛒 Shopping cart with quantity control
* 💳 Checkout system (COD, Card, UPI)
* 📦 Order tracking & history
* ⚙️ Admin dashboard (products, orders, users)
* 📱 Fully responsive design

## 🧑‍💻 Tech Stack

* HTML5
* CSS3
* JavaScript (Vanilla)
* LocalStorage (for data simulation)

2. Open `ecommerce.html` in your browser

## 🎯 Purpose

This project is built for learning and demonstrating core web development concepts and how an e-commerce platform works without a backend.
